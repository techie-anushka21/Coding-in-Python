Note: -
- During my initial learning phase, I referred some files of List, Set, and Tuple "Methods" as "Functions", for e.g.: 1. List function: append(), which should be: 1. List method: append().
- The correct terminology is "Method" and not "Function".
- This has been mentioned for Conceptual Clarity.
- Also, note that list(), set(), tuple(), and dict() are "built-in Constructor Functions". Hence, they cannot be simply called list, set, tuple, or dictionary methods (during list, set, and tuple commits I do have mentioned them as "method", but again, that was because I was in my initial learning phase).
